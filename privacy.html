Privacy Policy

Ammonite is committed to protecting your privacy. Last updated: October 2026.

Data We Collect

Ammonite collects only the minimum data necessary:

  • User IDs — to track economy, levels, warnings, and permissions.
  • Guild IDs — to store per-server configuration and settings.
  • Message Content — processed in real-time for commands, proxy tag matching, global chat, prefix commands, and auto-moderation. It may be stored when part of a moderation action, ticket, or user-submitted report.
  • Moderation Records — warning reasons, ban/mute durations, moderator IDs, timestamps.
  • Economy Data — wallet and bank balances, transaction history.
  • Levelling Data — XP totals, level progress, leaderboard rankings.
  • Proxy Data — proxy member names, display names, tags, and avatar URLs (all user-provided).
  • Role Persistence Data — role IDs stored for users who leave so roles can be reassigned on rejoin.
  • Suspicious Account Records — user IDs flagged by automated detection, with notes.
  • Music Playlists and Preferences — playlists you create and command privacy settings.
  • Reports and Tickets — submitted bug report text and ticket metadata. Ticket messages and transcripts are stored in Discord channels.

How Data Is Stored

Bot records are stored locally on the bot host machine. Data is kept in memory while the bot runs and persisted locally. No analytics or telemetry is collected.

Key GuaranteesData is not sold or used for advertising. Music commands send the search query or track URL needed for playback to the selected music provider. Discord interactions, webhooks, and ticket messages use Discord's API.

Data Retention

  • Economy, levelling, moderation, playlist, and preference records remain until deleted with /deletedata or removed by the bot operator. Removing the bot does not erase its local files.
  • Role snapshots remain until a server administrator clears them or the user runs /deletedata. Restoring a snapshot does not remove it.
  • Closed ticket channels are automatically deleted after 14 days unless archived. Ticket conversations and transcripts are stored in Discord.
  • Server configuration is managed by server administrators and may remain after the bot leaves. Server owners may request deletion by contacting the bot owner.

Your Rights

  • View your data — economy balances, levels, warnings, and proxy members are all visible through bot commands.
  • Request deletion using /deletedata. This removes your stored economy and levelling data, warnings, moderation records where you are the subject, reports linked to your account, playlists, preferences, role snapshots, and proxy members/groups.
  • Opt out of features — ask a server admin to adjust your permissions (e.g., deny globalchat.use).
Server AdministratorsTicket conversations remain under server administration; ask an admin to remove a ticket or its transcript. Server administrators can contact the bot owner to request removal of server-specific records.

Privileged Gateway Intents

  • Guild Members (GUILD_MEMBERS) — required for role persistence, suspicious account detection, welcome messages, and member cache for moderation.
  • Message Content (MESSAGE_CONTENT) — required for proxy tag matching, prefix command parsing, global chat forwarding, and auto-moderation filtering.
  • Presence (GUILD_PRESENCES) — required for suspicious account detection (analysing account age and presence patterns).

Non-privileged intents used: GUILD_MESSAGES, GUILD_MESSAGE_REACTIONS, DIRECT_MESSAGES.

Global Chat & Webhooks

The Global Chat feature relays messages between linked channels via Discord webhooks. Relayed messages have a [GC] prefix. Messages are rate-limited and content-capped. Message content is forwarded in real-time and not stored after relay.

Proxy System & Webhooks

The Proxy system sends messages via webhooks using user-configured display names and avatars. Servers can enable a [proxied] indicator. All proxy data can be deleted at any time by the user.

Contact

  • Use /deletedata to erase your personal data at any time.
  • Contact the bot owner through the support server or Discord DM.
  • Server owners can contact the bot owner for server-level data requests.

Moderation

/ban Ban a user from the server (permanent or timed) mod.ban

Syntax

/ban <user> [duration] [reason]

Parameters

NameTypeRequiredDescription
userUserYesThe user to ban
durationStringNoDuration of the ban. Omit for permanent. Formats: 1d, 2h, 30m, 1w, 12h30m
reasonStringNoReason for the ban (logged in mod history). Defaults to "No reason provided"

Examples

/ban @John 7d Repeated rule violations — Bans John for 7 days
/ban @Spammer — Permanently bans a user with no reason
/ban @User 2h30m Cooling off — Bans for 2 hours and 30 minutes

Details

  • Deletes the user's messages from the last 7 days when banning.
  • If a duration is specified, the bot will automatically unban the user after the time expires.
  • A DM notification is sent to the user (if /punishment-dm is enabled), including the reason, duration, and an appeal button.
  • The action is logged to the mod history, accessible via /hist.
  • Role hierarchy is enforced — you can only ban users with roles below yours.

/wordfilter Manage the server's custom word and regex phrase filter mod.wordfilter

Subcommands

SubcommandDescription
add <pattern>Add a plain word or regex pattern to the filter (max 100 patterns)
remove <pattern>Remove a pattern by text, ignoring letter case
removeat <index>Remove a pattern by its 1-based list index
listShow all current filter patterns, status, and action
clearRemove all patterns
enableEnable the word filter
disableDisable the word filter
action <delete|warn|delete+warn>Set what happens when a message matches

Notes

  • Plain terms match whole words or phrases without case sensitivity. Regex metacharacters enable regex matching.
  • Members with the automod.wordfilter.bypass permission are exempt
  • The master AutoMod switch in /settings pauses the word filter along with the other checks.
  • Action delete+warn removes the message and issues an automatic warn logged to the moderation log channel

Examples

/wordfilter add badword
/wordfilter add \b(bad|terrible)\s+word\b — regex pattern
/wordfilter action delete+warn

/prefix Configure prefix command settings admin.settings

Syntax

/prefix <action> [prefix]

Subcommands

  • enable — enable prefix commands (resets to ! if none configured)
  • disable — disable prefix commands entirely
  • add <prefix> — add a new prefix (e.g. ? or sb!)
  • remove <prefix> — remove a prefix; removing the last one auto-disables prefix commands
  • set <prefix> — replace all prefixes with a single one
  • status — show current prefixes and enabled/disabled state

Details

  • Prefix commands are separate from slash commands and are disabled by default.
  • Prefixes can be 1–16 characters long (no spaces, no /).
  • If all prefixes are removed, prefix commands are automatically disabled.
  • Re-enabling with no prefixes configured will reset to !.

Quick Ban Permanently ban a user from the right-click menu mod.ban · User menu

How to use

Right-click any user → Apps → Quick Ban.

Details

  • Requires the mod.ban permission.
  • Issues a permanent ban and deletes messages from the last 7 days.
  • Logs the action and sends a punishment DM if enabled.
  • For timed bans, use /ban <user> [duration] [reason] instead.
